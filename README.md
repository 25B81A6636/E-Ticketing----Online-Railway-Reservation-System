# E-Ticketing----Online-Railway-Reservation-System
E-Ticketing is an online railway reservation system that allows users to search trains, check seat availability, book and cancel tickets, and make online payments. It generates a PNR and electronic ticket after successful booking. The system reduces manual work, saves time, and provides convenient and efficient railway reservation services.
